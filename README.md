# DGM Studio · ενημερώσεις

Από εδώ το DGM Studio ελέγχει για νέα έκδοση (κουμπί «Έλεγχος για ενημερώσεις» και αυτόματα μία φορά την εβδομάδα).

- `latest.json`: η τελευταία έκδοση, τα νέα της και το link λήψης. Είναι υπογεγραμμένο με το κλειδί ενημερώσεων
  `upd-2026-1` και το πρόγραμμα δέχεται μόνο αυτή την υπογραφή.
- Τα αρχεία `DGM_Studio_<έκδοση>_Update.exe` ανεβαίνουν ως Releases. Δουλεύουν μόνο με ενεργή άδεια.

Εδώ δεν μπαίνει κώδικας ούτε στοιχεία πελατών.
